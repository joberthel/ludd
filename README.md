# ludd

A terminal-based (TUI) orchestrator and control plane for managing parallel background agents.

## Tech Stack

- **CLI & UI:** [Pastel](https://github.com/vadimdemedes/pastel), [Ink v8](https://github.com/vadimdemedes/ink), `@inkjs/ui`, React 19
- **Protocol & Validation:** `@modelcontextprotocol/server`, [Zod](https://zod.dev/)
- **Testing:** [Vitest](https://vitest.dev/), `ink-testing-library`
- **Tooling & Quality:** TypeScript, ESLint (`@antfu/eslint-config`), `simple-git-hooks`, `lint-staged`, `commitlint`

## Project Structure

```
.
├── dist/                    # Compiled output (generated by `npm run build`)
├── source/                  # Contains TUI source code and unit tests
│   ├── cli.tsx              # Entry point for Pastel
│   ├── commands/            # CLI command definitions (Pastel routes)
│   ├── components/          # Reusable Ink TUI components
├── CODING_GUIDELINES.md     # Coding Guidelines
├── commitlint.config.mjs    # Conventional Commits configuration
├── eslint.config.mjs        # Unified ESLint + Stylistic configuration
└── tsconfig.json            # TypeScript configuration (rootDir: "source")
```

## Development Scripts

| Command            | Description                                               |
|--------------------|-----------------------------------------------------------|
| `npm run dev`      | Run the CLI in development watch mode via Pastel          |
| `npm run build`    | Compile TypeScript and generate CLI metadata into `dist/` |
| `npm test`         | Run the test suite once via Vitest                        |
| `npm test:watch`   | Run the test suite watcher via Vitest                     |
| `npm run lint`     | Check code style and lint rules via ESLint                |
| `npm run lint:fix` | Auto-fix lint and formatting issues across the project    |

## Git Workflow & Conventions

This repository enforces [Conventional Commits](https://www.conventionalcommits.org/) and automated code formatting via `simple-git-hooks`:

* **`pre-commit`:** Automatically runs `lint-staged` (`eslint --fix`) on staged files.
* **`commit-msg`:** Validates commit messages against `commitlint.config.mjs`.
